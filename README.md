Selamat datang di **Modern Fresh Graduate Portfolio Template**! Repositori ini dirancang khusus untuk membantu para mahasiswa tingkat akhir, pencari kerja (*job seekers*), dan developer pemula yang membutuhkan *personal branding* yang memukau tanpa harus mendesain segala sesuatunya dari nol. 

Proyek ini dibuat menggunakan teknologi **HTML5, Tailwind CSS (v3), dan Vanilla JavaScript**. Struktur kodenya dibuat sesederhana mungkin agar siapa pun yang baru belajar pemrograman web dapat dengan mudah memodifikasi kontennya hanya dalam hitungan menit.

---

## ✨ Fitur Utama

Template portofolio ini dilengkapi dengan berbagai fitur modern yang sangat disukai oleh industri saat ini:

*   🎨 **Desain Elegan & Profesional:** Menggunakan font *Plus Jakarta Sans* dan palet warna modern yang memberikan kesan bersih, rapi, dan tepercaya di mata *recruiter*.
*   🌓 **Sistem Dark Mode Otomatis:** Dilengkapi dengan fitur saklar tema gelap dan terang. Sistem ini secara otomatis mendeteksi preferensi tema pada perangkat pengguna dan menyimpannya di *LocalStorage*.
*   📱 **Fully Responsive Layout:** Tampilan website telah diuji dan dioptimalkan untuk berbagai ukuran layar, mulai dari smartphone layar kecil, tablet, hingga monitor desktop beresolusi tinggi.
*   🎬 **Animasi Halus (AOS Library):** Efek transisi dan *fade-up* saat halaman di-scroll ke bawah memberikan kesan interaktif, hidup, dan premium ala agensi profesional.
*   📩 **Form Kontak Siap Pakai:** Menggunakan integrasi *Formspree*. Pengguna template tidak perlu membangun sistem *backend* atau server sendiri untuk menerima pesan email dari calon klien atau perusahaan.

---

## 📂 Struktur File

Di dalam repositori ini, terdapat dua versi file HTML utama yang bisa Anda gunakan secara fleksibel tanpa saling menimpa:
*   `index.html` : Versi standar portofolio dengan kustomisasi penuh yang siap diunggah.
*   `index-react.html` : File alternatif yang disiapkan bagi mereka yang ingin melakukan migrasi komponen ke ekosistem React.
*   `app.js` : Mengatur logika utama untuk fitur *dark mode* interaktif.
